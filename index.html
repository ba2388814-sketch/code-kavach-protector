HTML source hardening tool — client-side, কোনো ডেটা সার্ভারে যায় না পলিমরফিক আউটপুট

আপনার HTML পেস্ট করুন — নিচের অপশন অনুযায়ী কোড মিনিফাই, মাল্টি-লেয়ার এনকোড (প্রতিবার এলোমেলো ক্রমে), চাংক-স্প্লিট ও ভ্যারিয়েবল-র‍্যান্ডমাইজ করে এমন একটি ভার্সন তৈরি হবে যা সাধারণ ফাইল/টেক্সট ভিউয়ার দিয়ে সহজে বোঝা যায় না, অথচ ব্রাউজার/ওয়েবভিউতে আগের মতোই কাজ করে। জেনারেট করার পর আউটপুট স্বয়ংক্রিয়ভাবে একটা লুকানো ফ্রেমে চালিয়ে যাচাই করা হয় যে এটা ঠিকমতো লোড হচ্ছে কিনা।

ব্যাচ প্রসেসিং একাধিক ফাইল → ZIP

উপরে সেট করা সব অপশন (মিনিফাই, এনকোডিং লেয়ার, অ্যান্টি-ইন্সপেকশন ইত্যাদি) প্রতিটি ফাইলে প্রয়োগ হবে — প্রতিটি ফাইলের নিজের র‍্যান্ডম কী/ভ্যারিয়েবল-নাম থাকবে। প্রতিটি ফাইল ZIP-এর ভেতরে নিজস্ব প্রজেক্ট ফোল্ডার (index.html + css/secure.css + js/secure.js) হিসেবে থাকবে।
মাথায় রাখুন:
  • এই টুল শুধু কপি-পেস্ট এবং সাধারণ ফাইল/টেক্সট ভিউয়ারে সোর্স পড়া নিরুৎসাহিত ও কঠিন করে। এটা কোনো এনক্রিপশন না — একজন দক্ষ ডেভেলপার ব্রাউজারের রানটাইম আউটপুট থেকে চূড়ান্ত HTML দেখে ফেলতে পারবেন। সংবেদনশীল ডেটা (পাসওয়ার্ড, API key, পেমেন্ট লজিক) কখনো শুধু ক্লায়েন্ট-সাইডে না রেখে সার্ভারে রাখুন।
  • এই টুল কোডের ফাংশনালিটি অক্ষত রেখে শুধু সোর্স পড়া কঠিন করে — মূল HTML/CSS/JS-এর ভ্যারিয়েবল/ফাংশনের নাম ভাঙে না, তাই onclick="" এর মতো ইনলাইন কলগুলো নিরাপদ থাকে।
  • ছবি/CSS/JS-এর লিংক যেমন ছিল তেমনই আউটপুটে থাকে — প্রোটেক্টেড ফাইলটা যদি অরিজিনাল ফাইলের একই ফোল্ডারে/URL-এ রাখেন তাহলে রিলেটিভ লিংকও ঠিক চলবে। ফোল্ডার পাল্টালে Base href ফিল্ডে সেই ডিরেক্টরির পুরো URL দিন, অথবা ছবি/CSS-এ absolute URL ব্যবহার করুন — এটাই সবচেয়ে নিরাপদ।
  • DevTools ডিটেক্ট ফিচারটি window এর outer/inner size পার্থক্য মেপে docked DevTools শনাক্ত করে — এটা false-positive দিতে পারে (যেমন ছোট স্ক্রিনে জুম করা থাকলে), তাই প্রোডাকশনে দেওয়ার আগে টেস্ট করে নিন।
  • টাইমিং-বেসড ডিবাগার ডিটেকশন ও কী-অস্পষ্টকরণ কপি-প্রতিরোধের মাত্রা আরও বাড়ায়, কিন্তু কোনোটাই দুর্ভেদ্য না — একজন দক্ষ ব্যক্তি ব্রাউজারের network/elements panel থেকে রানটাইমে তৈরি হওয়া চূড়ান্ত HTML সবসময় দেখতে পারবেন।
  • সেলফ-ডিস্ট্রাক্ট (ভিউ/সময়সীমা) সম্পূর্ণভাবে ভিজিটরের নিজের ব্রাউজারের localStorage-এ নির্ভরশীল — ভিজিটর চাইলে ব্রাউজার ডেটা মুছে, ভিন্ন ব্রাউজার/ডিভাইস বা ইনকগনিটো মোড ব্যবহার করে সীমা এড়াতে পারেন। এটা প্রকৃত সার্ভার-সাইড অ্যাক্সেস-কন্ট্রোলের বিকল্প না।
  • প্রজেক্ট-ZIP ডাউনলোডের জন্য ইন্টারনেট সংযোগ প্রয়োজন (JSZip লাইব্রেরি CDN থেকে লোড হয়)। সংযোগ না থাকলে সাধারণ ".html ডাউনলোড" বাটন ব্যবহার করুন।
  • প্রোডাকশনে দেওয়ার আগে সবসময় "নতুন ট্যাবে প্রিভিউ" দিয়ে টেস্ট করে নিন।
